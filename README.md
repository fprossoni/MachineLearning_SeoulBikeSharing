# MachineLearning_SeoulBikeSharing
O dataset contém informações sobre quantas bicicletas foram alugadas por hora na cidade de Seoul, com informações sobre: Data, Hora, Qtd de Bicicletas alugadas, Temperatura, Chuva, Neve, Umidade, Estação, Feriado, entre outros.  O objetivo do modelo será prever, dadas as condições de um determinado dia/hora, quantas bicicletas serão alugadas.
